# TokenDell

TokenDell provides a Real-Time Data Processing Service, leveraging Auto-Scaling and High-Performance Architecture for efficient Enterprise Platform operations.

With TokenDell, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/TokenDell.git`
2. `cd TokenDell`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure TokenDell, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
